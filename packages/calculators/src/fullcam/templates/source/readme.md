This folder includes valid plot files, exported from the FullCAM application. These have been used to capture the XML snippets for specific scenarios, which are then used in the `templates` folder.

### example-planting-events.plo

A scenario with events for each of the 4 species, using the standard events in the UI to populate details, either 'Block geometry' or 'Plant trees: natural regeneration in regeneration systems'

### 3-deforestation\*.plo

These are variations of the default deforestation example, using each different species as the starting point, which are then thinned with an event.
